# Harmony UI Platform

根据附图和prd生成可使用平台。界面完全按照附图的设计来实现，平台的主题支持深浅色切换，深浅色就是黑白色作为主题色，尽量不要在平台里出现大面积的其它颜色，确保整体视觉效果一致且协调。功能逻辑与实现参考prd
